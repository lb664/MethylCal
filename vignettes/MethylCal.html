MethylCal: Bayesian Calibration of Methylation Levels

Leonardo Bottolo

2026-11-04

This package allows the calibration of methylation levels using MethylCal, a Bayesian calibration tool based on INLA (Rue et al., 2009). The package permits the visualisation of the calibration curve derived from standard controls with known methylation percentages for a selected assay. It also allows the correction of methylation levels in case and control samples. If case samples are provided, MethylCal performs a differential methylation test to detect hyper- and hypo-methylated samples. In addition to MethylCal, the package includes the calibration and correction provided by two alternative methods (Warnecke et al., 1997; Moskalev et al., 2011).

This vignette provides a concise description of the package and the code required to replicate the plots presented in Ochoa et al. (2019).

Structure of the package

Two data sets are included in the package:

  1. The first contains methylation data on patients potentially affected by the Beckwith–Wiedemann syndrome (BWS). Human genomic control DNA with five distinct actual methylation percentages (0%, 25%, 50%, 75%, and 100%), 15 healthy control DNA samples, and 18 patient DNA samples are included. A full description of the BWS data set can be accessed by typing

     help(BWS_data)

  2. The second data set includes eight NF\(\kappa\)B-related genes in patients with celiac disease (Fernandez-Jimenez et al., 2014; Fernandez-Jimenez et al., 2012). Human genomic control DNA measured at eight distinct actual methylation percentages (0%, 12.5%, 25%, 37.5%, 50%, 62.5%, 87.5%, and 100%), 13 controls (C), 17 celiac patients at the time of diagnosis (D), and the same patients after two years of treatment with a gluten-free diet (T) are included. Further information can be obtained from

     help(Celiac_data)

The package also contains two utility functions, Formatting and TableFormatting. The former transforms the data into a format suitable for MethylCal analysis, while the latter converts the output obtained from the calibration and correction functions (see below) into the same data format used in the uploaded data sets. Further details are presented in

help(Formatting)
help(TableFormatting)

Several functions are available for data exploration and analysis:

  1. The primary function for data exploration is ExploratoryPlot. It visualises the methylation levels of the standard control samples. Several plots are generated, stratifying the methylation levels with respect to the actual methylation percentages (AMP), the CpG position, or both. For details, see

     help(ExploratoryPlot)

  2. WarneckeCalibrationPlot performs calibration of the standard control samples using the method presented in Warnecke et al. (1997). Similarly to other calibration functions, several plots are generated. In particular, to assess the goodness of fit of the estimated calibration curve, a scatter plot depicts the corrected methylation levels at each AMP for all CpGs within a targeted Differentially Methylated Region (DMR)/CpG island/gene. Details are presented in

     help(WarneckeCalibrationPlot)

  3. Visualisation of the Moskalev calibration (Moskalev et al., 2011) of the standard control experiment is obtained using the function MoskalevCalibrationPlot. The online help

     help(MoskalevCalibrationPlot)

    also provides instructions on how to plot the results of the two calibration tools (extension of the Warnecke et al. (1997) method and cubic polynomial regression) presented in Moskalev et al. (2011).

  4. MethylCal as presented in Ochoa et al. (2019) is implemented in the function MethylCalCalibrationPlot. In addition to the calibration plots, several goodness-of-fit measures are provided for each estimated model, including: mlik (marginal likelihood), DIC (Deviance Information Criterion), and RSS (Residual Sum of Squares). The function MethylCalCalibrationOutlierPlot includes outlier detection, and the models are refitted after removing the detected outliers. Plots are presented with and without outliers. Further information is available in

     help(MethylCalCalibrationPlot)
 help(MethylCalCalibrationOutlierPlot)

  5. The main functions for correcting methylation levels in case and control samples are MoskalevCorrection and MethylCalCorrection. Both functions return the corrected methylation levels for the samples analysed. If case samples are provided, both functions perform a differential methylation test (at a specified confidence level) to detect hyper- and hypo-methylated cases. For details, see

     help(MoskalevCorrection)
 help(MethylCalCorrection)

How to generate the plots presented in Ochoa et al. (2019)

Once the MethylCal package is loaded

library(MethylCal)

the figures presented in Ochoa et al. (2019) are obtained using the following commands:

  1. Figure 1 A and B are produced by typing

     data(BWS_data)
 AMP = c(0, 25, 50, 75, 100)
 data = Formatting(BWS_data, AMP = AMP)
 MoskalevCalibrationPlot(data, Target = "KCNQ1OT1")
 MoskalevCalibrationPlot(data, Target = "H19/IGF2")

    and selecting the 1st, 2nd, and 3rd plot for each targeted DMR.

  2. Figure 2 is generated with

     MethylCalCalibrationOutlierPlot(data, Target = "KCNQ1OT1")
 MethylCalCalibrationOutlierPlot(data, Target = "H19/IGF2")

    Since MethylCal detects two outliers in the targeted DMR H19/IGF2, running the analysis for this DMR may take several minutes.

  3. To generate Figure 3 A and B, the case/control samples must first be loaded:

     data = Formatting(BWS_data, AMP = AMP, n_Control = 15, n_Case = 18)

    then

     MoskalevCorrection(data, Target = "KCNQ1OT1", n_Control = 15, n_Case = 18)

    Similarly, for Figure 3 C and D:

     MethylCalCorrection(data, Target = "KCNQ1OT1", n_Control = 15, n_Case = 18)

    For both MoskalevCorrection and MethylCalCorrection, the list of hyper- and hypo-methylated cases detected by the differential methylation test (at the specified confidence level) is printed to the console.

  4. To generate Figure 4, the commands are

     corr_data = MoskalevCorrection(data, Target = "H19/IGF2",
                                n_Control = 15, n_Case = 18)
 corr_data = MethylCalCorrection(data, Target = "H19/IGF2",
                                 n_Control = 15, n_Case = 18)

    The function output corr_data can be used to generate a table of the corrected methylation levels for both case and control samples, in the same data format as the input data set, using

     output_data = TableFormatting(corr_data, n_Control = 15, n_Case = 18)

  5. Finally, for Figure 5, the celiac data set must first be loaded, specifying the AMP list and formatting the data for the analysis, including the number of case and control samples:

     data(Celiac_data)
 AMP = c(0, 12.5, 25, 37.5, 50, 62.5, 87.5, 100)
 data = Formatting(Celiac_data, AMP = AMP, n_Control = 13, n_Case = 34)

    before running the analysis

     MoskalevCalibrationPlot(data, Target = "NFKBIA")
 MoskalevCorrection(data, Target = "NFKBIA", n_Control = 13, n_Case = 34)

    and

     MethylCalCalibrationOutlierPlot(data, Target = "NFKBIA")
 MethylCalCorrection(data, Target = "NFKBIA", n_Control = 13, n_Case = 34)
